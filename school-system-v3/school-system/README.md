# 智慧校园管理系统（全员数据同步版）

一套**不依赖任何平台**、可部署在学校服务器上的学校管理系统。
前后端分离，数据统一存在服务器上，**老师、学生、家长在各自设备上访问同一个地址，数据实时共享同步**。

## 技术栈
- 后端：Node.js + Express（`server.js`）
- 前端：原生 HTML/CSS/JS（5 个独立页面，各角色界面完全不同）
- 数据：服务器端 `data/db.json`（无需安装数据库）

## 全员数据同步部署方法

### 第一步：在服务器上启动（只需做一次）
找一台**一直开着的电脑或云服务器**（学校内网机器也行），在上面执行：
```bash
cd school-system
npm install        # 第一次需要
node server.js     # 启动服务
```
看到 `学校管理系统已启动: http://localhost:3000` 就成功了。

> 想后台常驻运行（关掉终端也不停）：
> ```bash
> nohup node server.js &
> ```
> 或安装 pm2：`npm i -g pm2 && pm2 start server.js --name school`

### 第二步：全员访问同一个地址
假设这台服务器的 IP 是 `192.168.1.100`，那么：
- 老师、学生、家长在各自手机/电脑浏览器打开 **http://192.168.1.100:3000**
- 所有人看到的是同一份数据，老师录完成绩，学生和家长立刻就能看到
- 管理员发的通知，全员同步收到

> 云服务器记得在安全组/防火墙放行 3000 端口；学校内网用内网 IP 即可。

| 家长 | parent1 | parent123 | parent.html（绿色家长中心） |

## 每个角色的独立界面
- **管理员**：深色侧边栏 + 数据看板 + 学生/教师/收费管理 + 发布通知
- **教师**：蓝色工作台 + 我的班级、录成绩、记考勤、发班级通知
- **学生**：暖色卡片 + 我的成绩/课表/考勤/通知、提交请假
- **家长**：绿色中心 + 孩子成绩/考勤/缴费记录/学校通知

## 数据同步原理
所有数据（学生、成绩、考勤、收费、通知）都存在服务器的 `data/db.json` 里。
各角色端通过 API 读写同一份数据，因此：
- 老师在 A 电脑录成绩 → 学生在 B 手机、家长在 C 电脑立刻看到
- 管理员发通知 → 所有端同步收到
- 数据只需定期备份 `data/db.json` 这一个文件

## 目录结构
```
school-system/
├── server.js          # 后端服务（登录鉴权 + 所有 API）
├── package.json
├── data/db.json       # 数据文件（自动生成，全员共享，定期备份这个文件）
└── public/
    ├── login.html     # 登录页
    ├── admin.html     # 管理员界面
    ├── teacher.html   # 教师界面
    ├── student.html   # 学生界面
    └── parent.html    # 家长界面
```

## 自定义
- 加老师/学生/家长账号：编辑 `data/db.json` 的 `users` 数组
- 改学校名称、配色：对应 HTML 文件里搜文字直接改
- 改端口：`PORT=8080 node server.js`
- 数据备份：复制 `data/db.json` 到其他位置即可
