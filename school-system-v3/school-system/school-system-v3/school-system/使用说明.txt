        学校管理系统 - 使用说明
════════════════════════════════════════

【第一次使用】
1. 安装 Node.js（免费，只需装一次）
   打开 https://nodejs.org ，下载 LTS 版本，一路下一步安装。

2. 双击本文件夹里的「启动.bat」
   - 第一次会自动安装依赖，等 1-2 分钟
   - 之后启动只需几秒

3. 浏览器会自动打开系统页面
   地址：http://localhost:3000

════════════════════════════════════════

【演示账号】
  管理员（校长）  admin      / admin123
  教师           teacher1   / teacher123

  家长           parent1    / parent123

════════════════════════════════════════

【全员数据同步（重要）】
要让老师、学生、家长在各自手机/电脑上看到同一份数据：

1. 把这个文件夹放到一台「一直开着的电脑」上
   （学校办公室电脑、机房服务器、云服务器都可以）

2. 在那台电脑上双击「启动.bat」启动服务

3. 查看那台电脑的 IP 地址（Win+R 输入 cmd，再输入 ipconfig，
   看 IPv4 地址，比如 192.168.1.100）

4. 其他人在浏览器打开：http://那台电脑的IP:3000
   例如：http://192.168.1.100:3000

5. 所有人看到的就是同一份数据，实时同步。

════════════════════════════════════════

【日常使用】
- 启动：双击「启动.bat」
- 停止：直接关闭那个黑色命令行窗口
- 数据备份：复制 data 文件夹里的 db.json 文件即可
- 加账号：用记事本打开 data\db.json，在 users 数组里添加
